# LaTeX Math Symbols

In **Obsidian**, you can write any mathematical or Greek symbol using LaTeX syntax wrapped in dollar signs (`$`).

Here is a comprehensive reference guide to the most common math symbols and how to write them.

## Greek Letters

| Symbol                | Markdown/LaTeX        | Symbol                | Markdown/LaTeX        |
| --------------------- | --------------------- | --------------------- | --------------------- |
| $\alpha$              | `$\alpha$`            | $\beta$               | `$\beta$`             |
| $\gamma$              | `$\gamma$`            | $\delta$ / $\Delta$   | `$\delta$` / `$\Delta$` |
| $\theta$              | `$\theta$`            | $\lambda$             | `$\lambda$`           |
| $\pi$                 | `$\pi$`               | $\sigma$ / $\Sigma$   | `$\sigma$` / `$\Sigma$` |
| $\omega$ / $\Omega$   | `$\omega$` / `$\Omega$` | $\phi$              | `$\phi$`              |

> **Tip:** Capitalising the first letter of the command (e.g., `\Delta`) gives you the uppercase Greek letter.
